Uso de datos

Se le informa de que la recopilación y tratamiento de los datos de carácter personal tiene como finalidad el mantenimiento de la relación comercial y el desempeño de mejorar otras actividades propias de MalBot.

Sus datos no los tratará terceros, únicamente los tratará MalBot. Para que el usuario pueda tener más información puede enviar un correo al correo : malbot@gmail.com . Con asunto : Privacidad de datos, se contestará cuanto antes.

Privacidad y protección de datos

Respecto a la ley Orgánica de Protección de Datos de Carácter Personal se debe :

  1. Se necesita el consentimiento expreso del usuario para poder realizar el tratamiento de datos personales.

    (se encuentra el consentimiento en el propio formulario de contacto).

  2. Solo se recopilarán los datos imprescindibles para poder llevar a cabo los servicios solicitados por el usuario.
  3. Los datos personales tendran un limite de conservación. Como máximo se almaceneran durante un mes, pasado el mes se borraran.
  4. Los responsables y encargados del tratamiento de datos así como todas las personas que intervengan en cualquier fase de este estarán sujetas al deber de confidencialidad al que se refiere el artículo 5.1.f) del Reglamento (UE) 2016/679.
  5. El usuario tiene derecho a saber para qué van a ser tratados sus datos, quien es el responsable de ellos y cual es su tratameinto.
  6. Los datos personales de los usuarios estarán tratados de manera legal, recogidos con fines determinados, exactos y actualizados.
- En concreto este sitio web es un proyecto con fines académicos. Por lo cual significa que no tiene fines reales. -
